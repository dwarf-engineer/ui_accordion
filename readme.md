# UI Accordion for Gallery or Navigation

![Скриншот работающего приложения](/assets/readme-1.png)

## Как запустить

- Скачайте проект;
- Откройте проект в вашей IDE;
- Если используете VS Code, то рекомендую запускать проект с помощью плагина [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer). 

Дополнительных настроек запуска проект не требует, все изображения лежат в папке `assets` и могут быть легко заменены на необходимые вам. 

В карточки можно встроить текст и ссылки для навигации. Проект легко масштабируется и адаптируется.
